Configuration Guides for Wireless VirtuaTilt.

Published on the new dedicated Wiki page with a dedicated Virtual Pinball AI chatbot here: https://virtuatiltwiki.3dptronics.com/
> [!TIP]
> **[VirtuaTilt Pulse](https://virtuatiltwiki.3dptronics.com/feedback/virtuatilt-pulse/)**, our Windows app, can do the DOF and DOFLinx steps of these guides for you: it checks your PC, fixes what is missing and tells you what is left for you, with the link and the folder.

> [!IMPORTANT]
> **3DPTronics supports the VirtuaTilt controller hardware only.** These guides are a *compendium* to help you connect your VirtuaTilt to third-party pinball software (VPX, Future Pinball + BAM, DOF/DOFLinx, PinEvent, PinUP Popper, etc.). We do **not** provide official support for any third-party software referenced here — for software-specific issues, please refer to each project's own documentation and community channels.
